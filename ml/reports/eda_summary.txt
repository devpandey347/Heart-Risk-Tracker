======================================================================
  SECTION 8 — FEATURE DESCRIPTIONS (UCI)
======================================================================
  age       : Age in years (29–77 in this dataset)
  sex       : 1 = male, 0 = female
  cp        : Chest pain: 1=typical angina, 2=atypical, 3=non-anginal, 4=asymptomatic
  trestbps  : Resting blood pressure in mmHg on admission to hospital
  chol      : Serum cholesterol in mg/dl
  fbs       : Fasting blood sugar > 120 mg/dl: 1=true, 0=false
  restecg   : Resting ECG: 0=normal, 1=ST-T wave abnormality, 2=left ventricular hypertrophy
  thalach   : Maximum heart rate achieved (bpm)
  exang     : Exercise-induced angina: 1=yes, 0=no
  oldpeak   : ST depression induced by exercise relative to rest
  slope     : Slope of peak exercise ST segment: 1=up, 2=flat, 3=down
  ca        : Number of major vessels (0–3) coloured by fluoroscopy  ⚠ has missing values
  thal      : Thalassemia: 3=normal, 6=fixed defect, 7=reversible defect  ⚠ has missing values
  target    : Diagnosis (0=no disease; 1–4=disease; mapped to binary for ML)

======================================================================
  SECTION 9 — KEY OBSERVATIONS (EDA Summary)
======================================================================
  1. DATASET SIZE: 303 patients, 13 features + 1 target — a small but well-studied dataset.
  2. MISSING VALUES: Only 'ca' and 'thal' have missing values (6 rows total — ~2% of data).
     These will be imputed in the preprocessing pipeline, not dropped.
  3. CLASS BALANCE: 164 no-disease (54.1%) vs 139 disease (45.9%) — mildly imbalanced.
     Standard stratified train/test split will handle this adequately.
  4. NUMERICAL FEATURES:
     • 'thalach' (max heart rate) tends to be LOWER in disease patients — a strong signal.
     • 'oldpeak' (ST depression) tends to be HIGHER in disease patients — another strong signal.
     • 'age' and 'trestbps' show moderate separation between classes.
     • 'chol' shows minimal separation — a weaker discriminator here.
  5. CATEGORICAL FEATURES:
     • 'cp' (chest pain type 4 — asymptomatic) is strongly associated with disease.
     • 'exang' (exercise angina = 1) is highly associated with disease.
     • 'sex' (male=1) shows higher disease prevalence in this dataset.
     • 'thal' (reversible defect = 7) is strongly associated with disease.
  6. CORRELATION CAVEAT: Pearson correlation is computed only for numerical features.
     Categorical features (like 'sex', 'cp', 'thal') require Cramér's V or phi-coefficient
     for meaningful correlation estimates — not done here to keep the script simple.
  7. DATASET LIMITATIONS:
     • Only 303 patients — generalization to the real world is limited.
     • All patients are from one hospital (Cleveland Clinic Foundation, 1988).
     • Gender, ethnicity, and age distributions may not represent the general population.
     • This dataset CANNOT be used for clinical diagnosis — educational use only.
